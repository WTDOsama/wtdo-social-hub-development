# WTDO Social Hub 🟢

**مركزك الشخصي لإطلاق جميع تطبيقات التواصل والمواقع المفضلة من مكان واحد.**

Developed by **WTDOsama** · © 2026 All Rights Reserved

تطبيق ويب تقدمي (PWA) شخصي، عربي RTL بالكامل، بواجهة داكنة فاخرة (أخضر داكن + تركوازي + ذهبي). يعمل دون خادم خلفي — كل بياناتك محفوظة محليًا على جهازك.

---

## ✨ الميزات

- **لوحة رئيسية**: ترحيب باسم المالك، التاريخ بالعربية، بحث فوري (عربي/إنجليزي مع تطبيع الهمزات والتشكيل)، تصنيفات بعدادات، وشريط وصول سريع للمفضلة.
- **15 تطبيقًا افتراضيًا** بأيقوناتها الرسمية وألوان علاماتها: واتساب، واتساب للأعمال، يوتيوب، يوتيوب ستوديو، إنستغرام، تيك توك، فيسبوك، ماسنجر، تيليجرام، إكس، جيميل، جوجل درايف، لينكدإن، سناب شات، بينتريست.
- **إدارة كاملة**: إضافة/تحرير/حذف (بتأكيد)/إخفاء/مفضلة/ترتيب بالسحب والإفلات أو بالأسهم (لمسي).
- **نموذج غني**: تحقق صارم من الروابط (http/https فقط)، أيقونات جاهزة (30+ علامة)، إيموجي، رفع صورة (قص تلقائي 128×128)، أو حرف تلقائي ملون. معاينة حية للبطاقة.
- **مواقعي واختصاراتي**: قسم مستقل لأي مواقع/خدمات مع اقتراحات جاهزة (ChatGPT، GitHub، Claude، Notion…).
- **إطلاق ذكي**: أندرويد → Intent بالحزمة الرسمية مع تراجع مضمون للموقع، iOS → Universal Links، سطح المكتب → تبويب آمن مقطوع الـopener. لا iframes ولا كلمات مرور إطلاقًا.
- **تخصيص**: اسم التطبيق والمالك، 5 ألوان تمييز، 3 أحجام بطاقات، إظهار/إخفاء الأوصاف وشريط الوصول السريع، التصنيف الافتراضي، إعادة ضبط.
- **نسخ احتياطي**: تصدير/استيراد JSON مع تحقق صارم وتأكيد قبل أي استبدال + استعادة الافتراضية.
- **PWA**: قابل للتثبيت على أندرويد وسطح المكتب، صدفة اللوحة تعمل دون اتصال، مؤشر انقطاع واضح.

## 🚀 التشغيل

```bash
npm install
npm run dev        # تطوير
npm run build      # إنتاج → dist/
npm run preview    # معاينة نسخة الإنتاج
npm test           # 56 اختبار وحدة/تكامل (Vitest + jsdom + Node)
node scripts/e2e.mjs   # 21 فحص متصفح حقيقي (Chromium) — يتطلب build أولًا
npm run icons      # إعادة توليد أيقونات PWA من الشعار
```

> أول تشغيل لاختبارات المتصفح: `npx playwright install chromium --only-shell` (وعلى لينكس قد تحتاج `npx playwright install-deps chromium`).

## 🏗️ البنية

```
public/
  manifest.webmanifest      # بيان PWA (عربي، standalone، أيقونات)
  sw.js                     # Service Worker (تخزين الصدفة + SWR + خطوط)
  icons/                    # شعار SVG + PNG 192/512/maskable/apple
src/
  types.ts                  # الأنواع المركزية
  data/apps.ts              # التطبيقات الافتراضية والتصنيفات والإعدادات (المصدر الوحيد)
  data/brands.ts            # أيقونات العلامات الرسمية (simple-icons)
  lib/utils.ts              # تحقق الروابط، البحث، الإطلاق، النسخ الاحتياطي، الترتيب
  store.tsx                 # الحالة + حفظ LocalStorage فوري + تنبيهات + تثبيت PWA
  components/               # AppIcon, AppCard, AppForm, ui, layout
  views/                    # Dashboard, Manage, Sites, Settings
  test/                     # اختبارات Vitest (واجهة + منطق + PWA)
scripts/
  generate-icons.mjs        # توليد الأيقونات (sharp)
  e2e.mjs                   # اختبارات Chromium الحقيقية + لقطات شاشة
screenshots/                # لقطات من اختبارات المتصفح (دليل بصري)
```

- **التخزين**: مفتاح واحد `wtdo-social-hub:v1` في LocalStorage يضم التطبيقات والإعدادات وآخر الاستخدامات. كل تعديل يُحفظ فورًا، وكل تحميل يمر بتنظيف/تحقق كامل.
- **ملاحظة تطوير**: لون الخلفية اسمه `night` وليس `base` لتجنب اصطدام `text-base` بأداة حجم الخط في Tailwind v4.

## 📲 آلية إطلاق التطبيقات

| المنصة | السلوك |
|---|---|
| أندرويد + حزمة معروفة | `intent://…#Intent;scheme=https;package=…;S.browser_fallback_url=…` — يفتح التطبيق المثبت، وإلا الموقع تلقائيًا (سلوك كروم الأصلي) |
| iOS | رابط HTTPS العام (Universal Link) — يفتح التطبيق إن كان مثبتًا |
| سطح المكتب / بدون حزمة | الموقع الرسمي في تبويب جديد مقطوع الـopener |

الحزمة اختيارية لكل تطبيق ويمكن تعديلها من «خيارات متقدمة» في النموذج. لا تُطلب أو تُخزن أي بيانات اعتماد؛ تسجيل الدخول يتم في المواقع الرسمية فقط.

## 🔌 العمل دون اتصال (PWA)

- التثبيت يخزّن مسبقًا: `/`, `/index.html`, `manifest`, الأيقونات.
- التنقل: الشبكة أولًا → عند الانقطاع تُقدَّم الصدفة المخزنة.
- أصول نفس النطاق: stale-while-revalidate. خطوط Google: cache-first.
- **بعد تحديث النسخة**: غيّر اسم `CACHE` في `public/sw.js` (مثل `wtdo-social-hub-v2`) ليُحدَّث التخزين لدى المستخدمين.
- دون اتصال تعمل اللوحة والإعدادات كاملة؛ الخدمات الخارجية (واتساب، يوتيوب…) تحتاج إنترنت بطبيعتها.

## 💾 صيغة النسخة الاحتياطية

```json
{ "app": "wtdo-social-hub", "version": 1, "exportedAt": "…", "apps": [ … ], "settings": { … } }
```

الاستيراد يتحقق من الإصدار وبنية كل تطبيق ورابطه (http/https فقط) ويرفض الملفات التالفة كليًا دون لمس بياناتك، ويطلب تأكيدًا قبل الاستبدال.

## ▲ النشر على Vercel

**الطريقة 1 — من الواجهة:**
1. ارفع المشروع إلى مستودع GitHub/GitLab.
2. vercel.com ← New Project ← استورد المستودع.
3. الإعدادات تُكتشف تلقائيًا: Framework = **Vite**، Build = `npm run build`، Output = `dist`.
4. Deploy — لا حاجة لأي متغيرات بيئة أو Backend.

**الطريقة 2 — CLI:**
```bash
npm i -g vercel
vercel login
vercel --prod
```

ملاحظات:
- Vercel يوفر HTTPS تلقائيًا — شرط لازم لتسجيل Service Worker والتثبيت.
- ملفات `public/` (sw.js، manifest، الأيقونات) تُنسخ كما هي إلى جذر النشر.
- يعمل المشروع على أي استضافة ثابتة (Netlify، Cloudflare Pages، GitHub Pages مع تعديل المسارات).

## 🔒 الخصوصية

لا خوادم، لا تتبع، لا كلمات مرور. كل شيء في متصفحك. **مسح بيانات المتصفح يمحو الإعدادات** — صدّر نسخة JSON بانتظام (تذكير مدمج في صفحة الإعدادات).
